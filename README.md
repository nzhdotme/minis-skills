# minis-skills

我自己用于 Open Minis 的 Skills。每个文件夹是一个 Skill，入口为 `SKILL.md`。

| Skill | 用途 |
| --- | --- |
| [adult-content-creator](adult-content-creator/SKILL.md) | 简体中文成人向虚构创作 |
| [english-word-deep-analysis](english-word-deep-analysis/SKILL.md) | 英语单词或短语的深度解析 |
| [github](github/SKILL.md) | 通过 gh CLI 连接和操作 GitHub 仓库（Minis 版） |
| [image-line-reverse-prompt](image-line-reverse-prompt/SKILL.md) | 将图片反推为分行结构的中文复刻提示词 |
| [strict-multilingual-translator](strict-multilingual-translator/SKILL.md) | 严格只输出译文的多语言翻译 |
| [surge-docs](surge-docs/SKILL.md) | Surge 文档入口：按任务选择权威来源并防止引用过时信息 |
| [zh-en-equivalent-selector](zh-en-equivalent-selector/SKILL.md) | 中文词句的英文等值选择 |
