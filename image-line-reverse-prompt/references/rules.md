## 1. 核心原则与优先级

风格锚点优先于细节堆砌。先判断画面最接近哪类导演电影感、经典影像体系或摄影美学，再让该锚点控制滤镜、场景、人物、服饰、动作与机位。

复刻优先级：

1. 风格锚点
2. 画幅比例
3. 构图骨架
4. 机位视觉
5. 主体位置
6. 动作姿态
7. 服饰结构
8. 场景位置关系
9. 滤镜质感
10. 人物特征
11. 水印字段固定值

决定“像不像”的字段写得最具体，不平均分配细节。

## 2. 合规措辞

避免使用容易触发审核的成人化或挑逗性措辞，包括但不限于：诱惑、挑逗、性感、撩人、媚态、欲望、情欲、床照、私密、胸、上围、臀、蜜桃臀、翘臀、低胸、暴露、湿身、咬唇诱惑、跪姿挑逗。

优先替换为：氛围感、镜头表现力、时尚写真感、成熟写真感、修身轮廓、身体曲线、服装贴合感、背身轮廓、肩颈线条、落肩穿法、居家写真感、生活流写真感、唇部轻抿、嘴唇微张、水光唇妆。

人物明显未成年或年龄不明时：只做中性外观、服装、姿态和构图描述；将【身材描述】改为“自然体态，比例协调”，不得输出固定成人曲线描述。

## 3. 风格锚点

### 写法

使用：`近似 + 导演/作品/类型/摄影体系方向 + 关键视觉特征`。

示例：

- 近似胡金铨武侠电影风格，重点是屋檐高处、纱幔前景、暮色蓝粉调、人物静态凝视和古典武侠片场氛围。
- 近似王家卫式都市夜景电影感，重点是霓虹色彩、低照度环境、浅景深虚化、人物情绪化凝视和空间压缩。
- 近似岩井俊二式青春影像风格，重点是柔光过曝、低饱和色彩、轻颗粒、空气感和青春记忆感。
- 近似侯孝贤式静态长镜头电影感，重点是自然光、低对比、人物与空间关系、克制情绪和真实环境氛围。
- 近似张艺谋早期色彩电影风格，重点是高纯度色彩、强烈环境色块、仪式感构图和人物造型的视觉冲突。
- 近似黑泽明时代剧视觉风格，重点是低机位、强风感、群像空间、厚重布景和戏剧化天气氛围。
- 近似杜琪峰银河映像式冷硬夜景风格，重点是暗部压低、硬光切面、城市空间、人物站位和紧张感构图。
- 近似复古港风电影写真，重点是暖色室内光、胶片颗粒、生活流构图、港式服饰和旧照片质感。
- 近似千禧年数码相机生活流风格，重点是低清压缩、闪光直打、轻微失焦、随手拍构图和真实快照感。

无法准确判断时写：

- 近似某类电影摄影风格，重点是……
- 无明确导演指向，更接近……摄影体系。

不要为了套参考库而硬猜具体导演或作品。

### 参考方向

- 武侠/古风：胡金铨式武侠片、李翰祥式古典华丽、张艺谋早期色彩美学、黑泽明时代剧、徐克新武侠电影感。
- 都市夜景/情绪：王家卫式都市霓虹、杜琪峰银河映像冷硬夜景、侯孝贤静态空间、蔡明亮式孤独室内空间。
- 青春/生活流/柔光：岩井俊二式青春影像、是枝裕和式自然生活流、千禧年日系写真、复古 CCD 快照。
- 港风/复古：90 年代港片室内暖光、港风胶片写真、TVB 旧剧截图感、复古杂志写真。
- 棚拍/时尚：时尚杂志大片、复古胶片棚拍、极简摄影棚、强闪光时装摄影。

## 4. 字段规则

### 输出格式

普通反推的完整分行提示词必须放在一个 Markdown 代码块中，代码块覆盖【风格锚点】至【可替换变量】全部字段。质检模式仅将【问题质检】放在代码块外，【优化后分行法提示词】及其【可替换变量】必须合并放在同一个代码块中。

### 【比例】

只写原图画幅比例，如 `1:1`、`2:3`、`3:4`、`9:16`、`16:9`。无法精确判断时选择最接近的标准比例。

### 【滤镜】

必须服从风格锚点。按“拍摄设备感 + 光线状态 + 清晰度 + 柔焦程度 + 高光状态 + 色调 + 颗粒/压缩感”组织。

示例：

- 古风电影写真，蓝紫粉暮色调，强柔焦与薄雾朦胧感，高光轻微弥散，低对比，暗部带青蓝冷调，肤色柔亮，轻微胶片颗粒与旧照片纹理。
- iPhone 镜面快照，室内暖黄灯光，轻微失焦，低清压缩感，低对比，边缘轻微虚化，真实生活流自拍质感。
- CCD 闪光直拍，低清数码压缩质感，轻微过曝高光，柔焦美颜，边缘锐度不均，轻颗粒，浅粉蓝低饱和调色。
- 夜景闪光灯，强柔焦，薄雾朦胧感，高光弥散，bloom 发光感，低对比，边缘虚化，奶油化散景。

普通手机图不升级为高级棚拍；低清图不写高清精修；生活流不写成杂志大片。

### 【场景】

必须包含：主空间、左右前后位置关系、近景远景、关键道具、道具主次。

示例：

- 古风屋檐或城墙高处，背景是蓝粉渐变暮色天空，左侧大面积白色纱幔作为前景遮挡，右上有红色飘带从画面外垂落，远景有模糊陶罐与屋顶线条，背景道具保持虚化不要抢主角。
- 室内门口镜前，右侧近景是大面积木色门板，人物站在门框中间偏左，左后方房间里有白色椅子，浅色墙面与木地板，背景简洁。
- 室内卧室，白色皱褶床单大面积铺满画面，右侧蓝白格纹枕头与粉色抱枕，底部粉色复古电话，中下方白色小熊玩偶，右下少量蛋糕盘与蓝色蝴蝶结点缀，辅助元素不要抢主角。

### 【人物特征】

默认结构：`脸型与整体气质 + 发色发型 + 刘海/发饰 + 妆容 + 肤感 + 遮挡状态`。仅在画面确实支持时使用“韩国瓜子脸美女”；否则按可见脸型与气质描述，不臆测国籍或族裔。

写清发色、发型、刘海、发饰、眼妆、腮红、唇色、肤感和脸部遮挡。脸被遮挡时明确：脸部被手机、手或头发部分遮挡，只露少量侧脸或眼部。

示例：

- 瓜子脸女性，黑色半披散古风盘发，额前与脸侧有凌乱湿发丝，后侧红色细发带点缀，清冷古风妆容，灰棕眼影轻晕染，细长微上扬眼线，卧蚕轻提亮，低饱和豆沙粉唇，冷白柔雾肤感。
- 瓜子脸女性，浅棕色超长直发，黑白蝴蝶结发饰，脸部大部分被手机遮挡，只露少量侧脸，清透淡妆，淡粉腮红，低饱和粉唇，暖光肤感。

### 【服饰】

写结构，不只写风格名。制服、女仆装、Lolita、和服、泳装、角色服按顺序写：上身结构 / 肩袖结构 / 腰部结构 / 裙摆结构 / 腿部袜类 / 鞋子状态 / 配饰。

示例：

- 黑金孔雀羽纹和服，落肩穿法，肩颈线条明显，金色腰封，金色蝴蝶发簪，耳饰点缀。
- 黑白女仆风短袖连衣裙，黑色修身上身，白色荷叶边肩袖与领边，腰部白色围裙系带，后腰垂落白色蝴蝶结尾片，黑色外扩蓬蓬短裙，裙摆底部多层白色透明荷叶纱边明显外翻，黑色透肤连裤袜延伸至脚尖，赤足无鞋，手腕银色饰品。
- 浅蓝白条纹棉质蕾丝边吊带睡裙，胸前系带设计，荷叶边蕾丝装饰，裙摆自然褶皱，白色半透明蕾丝手套，白色短袜带浅蓝蝴蝶结图案，浅蓝色玛丽珍鞋。

### 【动作】

必须包含：身体朝向、头部方向、手部动作、腿部动作、视线状态、姿态重心。

示例：

- 人物站在屋檐高处，身体微侧向镜头，头部轻微回转，眼神安静看向镜头，一只手轻扶纱幔边缘，另一只手自然垂落，衣袖与发带被微风带起。
- 人物背对镜子站立自拍，身体微微侧转，一只手举手机遮住脸部，另一只手自然下垂，头部微偏向手机，一条腿自然站立，另一条腿向后抬起并轻踮脚尖，长发顺背部垂落。
- 人物斜躺在床上，身体沿右下到左上斜向展开，一只手轻触嘴边，另一只手自然摊在床上，视线看向镜头，嘴唇微张，双腿屈起并抬向左上前景形成明显透视。

### 【机位视觉】

必须包含：拍摄方式、主体位置、脸部位置、前景内容、大面积背景、倾斜方向、透视方向。

示例：

- 中近景电影构图，镜头略低于人物视线，前景白色纱幔形成大面积虚化遮挡，人物位于画面中右区域，背景屋顶线条与暮色天空虚化，红色飘带从右上角垂入形成视觉引导。
- 镜面自拍视角，竖幅全身构图，人物与镜子有一定距离，画面轻微顺时针倾斜，人物位于画面中左区域，右侧木门占据大面积近景，门框与地面线条形成明显纵深。
- 高机位俯拍，广角手机感，中近景斜向构图，镜头贴近腿部前景，双腿占据左侧大面积前景形成强透视，脸部位于右侧中部最清晰，白色床单留白占画面大部分，背景道具略虚。

### 【身材描述】

成年人物固定输出：`s曲线身材，蚂蚁腰。` 不延伸、不增加高风险身体词。未成年人或年龄不明人物改为：`自然体态，比例协调。`

### 【水印】

固定输出：`无水印`。无论原图是否存在水印，都不识别、不描述、不复刻水印内容、位置或样式。

## 5. 风格联动

### 胡金铨式武侠

- 滤镜：古风电影、暮色、纱幔、低对比、薄雾。
- 场景：屋檐、城墙、竹林、纱幕、古典空间。
- 机位：中远景、侧向构图、前景遮挡、静态电影构图。
- 动作：克制、回眸、静立、衣袂轻动。

### 王家卫式都市夜景

- 滤镜：霓虹、低照度、色彩偏移、浅景深、胶片颗粒。
- 场景：夜晚街道、玻璃、霓虹、狭窄空间。
- 机位：近景、侧脸、遮挡、压缩空间、情绪化构图。
- 动作：安静凝视、微偏头、停顿感。

### 岩井俊二式青春影像

- 滤镜：柔光、轻微过曝、低饱和、空气感。
- 场景：校园、卧室、窗边、白色床单、自然光。
- 机位：高机位、轻俯拍、柔和生活流构图。
- 动作：自然、松弛、轻触、微笑或安静看镜头。

### 复古 CCD 生活流

- 滤镜：直闪、低清、压缩噪点、轻微失焦。
- 场景：真实生活空间，避免棚拍感。
- 机位：随手拍、镜面自拍、贴近前景、构图略不完美。
- 动作：自然抓拍，避免舞台化。

## 6. 质检模式

用户同时提供原图与生成图并要求质检时，只输出：

1. 【问题质检】：3–5 条直接差异。
2. 【优化后分行法提示词】：完整固定结构。
3. 【可替换变量】：固定结构。

质检优先级：风格锚点、构图骨架、机位视觉、主体位置、服饰结构、场景位置关系、滤镜质感、妆容脸部。不要讲理论，直接修正提示词。水印不参与差异质检，【水印】及其变量固定输出“无水印”。
